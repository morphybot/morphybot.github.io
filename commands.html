Commands

Morphy has 55 commands. Counting each subcommand, like /welcome channel, there are 190. Type / in any channel to use them, or run /help in your server to see the ones you can use.

Staff commands need the Discord permission shown, and everything else works for every member. Settings only change your own server.

Commands tagged Free work on every server. Commands tagged Premium need Morphy Premium on that server.

A few casino commands aren't listed here. Some start switched off, and staff can turn them on with /economy toggle.
