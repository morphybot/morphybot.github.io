Commands

This page lists 104 commands. Counting each subcommand, like /welcome channel, there are 379. Use / or /help in your server.

Staff need the permission shown. Other commands work for everyone. Settings apply to your server.

Commands tagged Free work on every server. Commands tagged Premium need Morphy Premium on that server.

A few casino commands aren't listed here. Some start switched off, and staff can turn them on with /economy toggle.
