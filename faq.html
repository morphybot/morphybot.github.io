Questions and answers

What is Morphy?

An all-in-one Discord bot. Welcome messages with picture cards, auto roles and role menus are free, and Premium adds tickets, applications, invite rewards, giveaways, polls, info panels, points, a casino and your server's own name and look for the bot.

How much is it?

The Free plan costs nothing and doesn't run out. Premium is $9.99/month (30 days) or $99.90/year (365 days) per server. How to pay is in the Morphy support server.

What's free, and what needs Premium?

Every server gets welcome messages and picture cards, goodbye messages, auto roles and role menus for free, plus /setup, /help, /subscribe and /showcase. No card needed. Premium adds tickets, branding, the casino, applications, giveaways, invite tracking, boosts, points, panels, anti-nuke, the do-not-post trap and more.

Does each server pay on its own?

Yes. Premium is per server. Paying for one server doesn't turn on Premium in another, even if you own both.

How do I set it up?

Invite Morphy with the Add Morphy button, then run /setup and follow the setup guide.

What happens when Premium ends?

The server goes back to the Free plan. Welcome messages and picture cards, goodbye messages, auto roles and role menus keep working, and so do /setup, /help, /subscribe and /showcase. Tickets, the casino, invite tracking, anti-nuke, the do-not-post trap and the other Premium features pause, and the bot's name, picture, banner and About Me in your server go back to Morphy's own look. Your settings are kept, and everything comes back when you renew. Paid time doesn't renew by itself, and the server owner gets reminders by DM before it ends.

Does Morphy touch my game server?

No. Morphy is Discord-only. It never asks for a game-server login or token, it doesn't connect to any game, and it doesn't show live server stats.

Does Morphy need Administrator?

No. Morphy asks for 15 permissions, and Administrator isn't one of them. They're listed below, each with what it's for.

Can I hide my server from the list on Morphy's website?

Yes. Every server is listed by default, and servers on the Free plan are in their own group. Staff with Manage Server can run /showcase off, and the server drops off the list within about 5 minutes. /showcase on puts it back. Age-restricted servers are never listed.

Where do I get help?

Open a ticket in the Morphy support server.
