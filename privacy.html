Morphy Privacy Policy

Last updated: October 4, 2026

This policy explains what information Morphy, a Discord bot, collects, why, and what you can do about it. "We" and "us" mean the people who run Morphy.

1. What we collect

Morphy only keeps what it needs to work in your server.

About servers

  • Server ID and name, and the settings your staff choose (channels, roles, messages, templates, images you upload for welcome cards or branding).
  • Plan status (Free or Premium) and dates, and a log of each time we add, change or end Premium by hand.
  • Payment reports: when staff press I've paid in /subscribe, we keep who sent it (their Discord user ID and name), the plan, how they paid and the name or note on the payment, so we can match it to the payment. The report is also sent to us in a Discord message.
  • ARK game servers your staff add with /servers (Premium): the server's address and port, and what the game server shows to anyone who asks: whether it's online, its name, map, player count, player limit and version, checked every 2 minutes. We keep a history of whether it was online and how many players it had for 30 days. For ARK: Survival Evolved servers, /servers players asks the game server for the names of the players on it and shows them in Discord. We don't save player names.
  • Nitrado link, only if your staff link one with /nitrado link: the Nitrado token, saved encrypted and never shown again to anyone, your staff included (only Morphy's code opens it, to ask Nitrado); the game servers it can see (ID, name, game and slot count); the token's scopes and expiry date; and who linked it and when. Server status, player names and activity logs are read from Nitrado when they're shown, kept in memory for a few minutes at most, and not saved.
  • If we add card payments later, Stripe will handle them and we'll only receive a customer or subscription reference. We'd never see or store card numbers.

About members (stored by Discord user ID)

  • Who opened, claimed and closed each ticket, its type and the answers to its questions. Transcripts are posted to your server's transcript channel.
  • Answers to staff applications, and who accepted or denied each one.
  • Who invited whom, when people joined or left, and whether an account looked brand new (the invite tracker).
  • Casino coin balances, point totals, cooldown times and a history of changes.
  • XP totals, this week's XP, when each member last earned XP, and weekly XP rewards (if staff turn XP and levels on).
  • Poll votes, giveaway entries and suggestions.

Messages

  • Morphy reads messages in your server only to run features you turn on, for example the do-not-post trap, XP for chatting, and text commands like !bj or !links. We don't store message content, except what's included in ticket transcripts, which are posted to your own server.

Email

  • If you email Morphy's support address, we get your email address and what you wrote, and use them only to answer you.

Website visitors

  • Our website sets no cookies and has no trackers. It's hosted on GitHub Pages, and its home page loads the server list from Morphy's server on Railway and the server icons from Discord, so GitHub, Railway and Discord see your IP address, like any website you visit. Discord's image server may also set a short-lived cookie of its own.

2. How we use it

Only to run Morphy's features for your server, keep your Premium working, match payment reports to payments, list your server on our website (see section 4), prevent abuse, fix problems, and contact people about their plan (for example Premium renewal reminders to server owners by DM, or a note to whoever sent a payment report). We don't sell your information, and apart from the server list in section 4, we don't use it for advertising.

3. Who we share it with

  • Discord, because Morphy runs on Discord.
  • Railway (our hosting and database provider), which stores the data above for us.
  • Stripe, if we add card payments later, to process them.
  • Google (Gmail), which holds emails sent to our support address.
  • Nitrado, only if your staff link a Nitrado account: Morphy sends Nitrado your token to read your game servers' status, players and activity log. Morphy never changes anything on Nitrado.
  • Anyone who visits our website, which shows the server list in section 4 (name, icon, member count, whether it has Premium or the Free plan, and a Join link if your staff add one).
  • To check a tracked ARK server, Morphy asks the game server directly over the internet, and for ARK: Survival Ascended it downloads Studio Wildcard's public server list. We don't send either of them anything about your Discord server or its members.
  • Anyone the law requires us to share with.

4. The server list on our website

Morphy's website has a list of the servers using Morphy. Every server is on it by default, on the Free plan or with Premium, except age-restricted servers. Servers on the Free plan show in a separate "Also using Morphy" group, below the servers with Premium. The list shows each server's name, icon and member count, plus a Join button if your staff add an invite with /showcase invite. The icon's link has the server's Discord ID in it, because that's how Discord's image links work. Nothing else about the server or its members is shown.

Staff with the Manage Server permission can run /showcase off to hide the server. It drops off the list within about 5 minutes. /showcase on puts it back. We can also take a server off the list ourselves.

5. How long we keep it

  • Server settings and member data are kept until you ask us to delete them, including after Morphy leaves your server. Premium settings stay saved while the server is on the Free plan, so you don't lose your setup if Premium starts again.
  • Payment reports and the log of Premium time we add by hand are kept the same way, so we can answer billing questions.
  • A Nitrado link (the encrypted token and the saved server list) is deleted when staff run /nitrado unlink, which works on the Free plan too, or when Morphy is removed from the server.
  • If you'd like your server's data deleted, open a ticket in the Morphy support server or email us (section 10), and we'll remove it.
  • A tracked ARK server's history is kept for 30 days. Removing the server with /servers remove deletes it and its history right away.
  • Casino money, points and similar data can also be reset by your server's staff at any time.

6. Your choices

  • Server owners can remove Morphy at any time and ask us to delete the server's data.
  • Staff can hide your server from the list on our website with /showcase off.
  • Members can ask us what we hold about them, or ask for it to be deleted, by opening a ticket in the Morphy support server (some records, like a server's own ticket transcripts, are controlled by that server).

7. Children

Morphy is for people old enough to use Discord under Discord's own rules. We don't knowingly collect information from anyone younger.

8. Security

Data is stored with our hosting provider and access is limited to running Morphy. Nitrado tokens are encrypted with AES-256-GCM, using a key kept only in our hosting settings, apart from the database. No system is perfectly secure, but we take reasonable steps to protect it.

9. Changes

We may update this policy. If the changes are important, we'll let server owners know.

10. Contact

Questions or requests? Open a ticket in the Morphy support server: https://discord.gg/Mp8c7ra6dx

If you can't use Discord, email morphybot.support@gmail.com.
